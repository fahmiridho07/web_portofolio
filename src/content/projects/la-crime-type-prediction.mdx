## Context

Crime data can reveal patterns across time, geography, and victim context. This project used historical LA crime data as a supervised learning problem, turning structured records into features that could support crime type prediction.

## Problem

The dataset contains multiple signals with imbalanced classes. The challenge was not only to train a model, but to compare model behavior under imbalance handling and evaluate the trade-off between accuracy and recall-oriented metrics.

## My Role

I worked on data preparation, model comparison, imbalance handling, and evaluation design.

## Approach

- Prepared features from event time, geographic location, and victim characteristics.
- Compared Decision Tree, Random Forest, Logistic Regression, SVM, Naive Bayes, and MLP models.
- Tested imbalance strategies including SMOTE, RandomOverSampler, and UnderSampler.
- Evaluated results using Accuracy, Precision, Recall, F1-score, and ROC-AUC.

## Key Decisions

The project compared several model families instead of relying on a single high-level score. That made it easier to understand how different algorithms responded to class imbalance and feature structure.

## Tech Stack

Python, Pandas, Scikit-learn, TensorFlow, Random Forest, Decision Tree, Logistic Regression, SVM, Naive Bayes, MLP, SMOTE, RandomOverSampler, and UnderSampler.

## Result

The work produced a reproducible supervised learning comparison with evaluation across common classification metrics, giving a clearer view of model trade-offs for crime type prediction.

## What I'd Improve

I would add stronger feature explainability, document confusion-matrix patterns per crime category, and include a clearer error analysis section for classes that remain difficult to predict.
