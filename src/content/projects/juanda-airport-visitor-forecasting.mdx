## Context

Airport visitor demand changes across time because of seasonality, travel patterns, and external operational factors. The project explored whether a sequence model could forecast visitor counts more effectively than simpler baselines.

## Problem

The core problem was to forecast future visitor counts from historical time-series data while keeping the comparison understandable and measurable.

## My Role

I handled preprocessing, normalization, model setup, baseline comparison, and forecasting evaluation.

## Approach

- Cleaned and normalized historical visitor data.
- Explored trend and seasonal behavior before modeling.
- Built a CNN-LSTM model to capture local sequence patterns and longer temporal dependencies.
- Compared CNN-LSTM against Random Forest and Linear Regression baselines.
- Evaluated model performance with RMSE.

## Key Decisions

The comparison included baseline models so the CNN-LSTM result could be judged against simpler alternatives, not just presented as a complex model by default.

## Tech Stack

Python, TensorFlow, Pandas, NumPy, CNN-LSTM, Random Forest, and Linear Regression.

## Result

Based on the CV notes provided, the CNN-LSTM model achieved lower RMSE than the baseline models.

## What I'd Improve

I would add rolling-window validation, visualize forecast intervals, and document how holidays or special travel periods affect forecast error.
